# Plazmic UI Studio 0.1.0

This is the first packaged release of the local EverQuest Legends layout
Studio.

## Included

- A one-file Linux x86-64 executable.
- A one-file Windows x86-64 executable with version metadata.
- Capture of an installed `plazmic-ui` or `default_modern` skin and one selected
  top-level `UI_*.ini` layout.
- The loopback-only browser Studio for window layout and validated XML edits.
- Explicit publish with timestamped skin and layout backups.
- `SHA256SUMS` for both executables.

The executables contain only Plazmic UI code, the Python runtime, and the static
Studio frontend. They do not contain EverQuest files, textures, layouts, or
other Daybreak assets.

## Start

Run `capture` once, then open the Studio:

```bash
./plazmic-ui-studio-linux-x86_64 capture \
  --game-dir "PATH TO EVERQUEST LEGENDS"
./plazmic-ui-studio-linux-x86_64 studio
```

On Windows PowerShell:

```powershell
.\plazmic-ui-studio-windows-x86_64.exe capture `
  --game-dir "C:\Path\To\EverQuest Legends"
.\plazmic-ui-studio-windows-x86_64.exe studio
```

On Linux, make the downloaded file executable first. The packaged Studio
supports `capture`, `studio`, and `publish`; repository-only `sync`, format,
lint, and offline install commands remain part of the Linux source workflow.

The first Windows executable is not Authenticode-signed, so Windows may show a
SmartScreen warning. Verify its SHA-256 value against `SHA256SUMS` before
choosing to run it.

See the repository user guide for platform-specific commands, workspace paths,
safety boundaries, and rollback instructions.
